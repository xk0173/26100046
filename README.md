# 🍽️ 오늘 뭐 먹지? (점심 메뉴 추천)

## 📝 프로그램 소개
매일 점심 메뉴를 고르기 어려워하는 분들을 위해 기획된 **웹 기반 메뉴 추천 프로그램**입니다. 
파이썬으로 작성된 기존 로직을 웹(HTML/CSS/JavaScript)으로 변환하여 스마트폰이나 PC 어디서든 편하게 접근할 수 있도록 제작했습니다.

## 💡 주요 기능 및 사용 방법
1. **메뉴 추천받기**: 화면 중앙의 카테고리 버튼(한식, 중식, 일식, 양식, 아무거나) 중 하나를 클릭하면, 룰렛(슬롯머신) 애니메이션 효과와 함께 랜덤으로 메뉴가 추천됩니다.
2. **나만의 메뉴 추가하기**: 하단의 입력창에서 원하는 카테고리를 선택하고 새로운 메뉴 이름을 적은 뒤 `➕ 리스트에 추가하기` 버튼을 누르면 나만의 메뉴가 등록됩니다. 이후 추천 시 해당 메뉴도 함께 랜덤 추첨 대상이 됩니다.
